## 프로젝트 로그

<details>
<summary>전체 로그 보기 (26.08.20 ~ 26.09.10)</summary>

### 26.09.10

- 노래 DB 상세 정보를 인라인 확장 대신 드로어(Drawer) UI로 전환
  - 포커스 트랩, 열기 전 포커스 위치로 복원, Escape 닫기 등 접근성 보강
  - `inert`로 배경 상호작용을 막는 방식이 카드 전환 기능을 깨뜨리는 회귀를 발견해 제거
  - React 커밋 단계의 포커스 복원 경합, 확대 이미지 모달이 드로어에 중첩될 때 Tab 포커스 트랩을 벗어나던 문제 수정
  - 확정된 실제 DB 스키마(NOT NULL 컬럼) 기준으로 불필요한 fallback 코드 정리
  - 곡/앨범 목록 정렬 방향 로직을 `sort.ts`로 공용화
- 버그 수정: 모바일 헤더 탭이 장시간 백그라운드 방치 후 사라지던 컴포지팅 버그 근본 수정
  - 실제로 스크롤되는 컨테이너가 없어 `sticky` 포지션이 기능적으로 무의미했는데, 이 불필요한 `sticky`가 크롬의 컴포지팅 버그 표면을 열어두고 있었음 — `relative`로 교체해 버그 유발 지점 자체를 제거
- 즛토피아 콘서트 아카이브 폴더·라우터 경로명을 `archive`/`concerts`에서 `lives`로 통일
- `song-db` 폴더 내 뷰 컴포넌트를 `components/`로 분리해 데이터·타입·정렬 로직과 구분
- 버그 수정: 전역 폰트가 create-next-app 기본값(Arial/Helvetica)으로 남아있어 윈도우·맥에서 폰트가 다르게 보이던 문제 (실제로는 아무 데도 안 쓰이고 있던 `Geist`를 `body`에 적용)
- NextVisit/NextEvent 포스터 클릭 시 외부 투어 링크 대신 `/info`로 이동
- PC 화면 좌측 하단에 앱 설치(PWA)/공유 버튼 추가
  - 설치 버튼은 `beforeinstallprompt`가 실제로 뜰 때만(=설치 가능할 때만) 노출
  - 공유는 Web Share API 우선 사용, 미지원 브라우저는 클립보드 복사 + 피드백으로 대체
- 전역 폰트를 Geist(라틴 전용)에서 IBM Plex Sans KR/JP + Plex Mono로 교체
  - Geist만으로는 한글·가나가 여전히 OS 기본 글꼴로 남아 있었는데, 언어별 전용 폰트를 얹어 OS와 무관하게 동일하게 보이도록 함
- 노래 DB 목록·앨범 상세 트랙 목록에 트랙 번호, 유튜브/응원 가이드 링크 아이콘 추가
  - 응원 가이드 콘텐츠와 Supabase 곡을 처음엔 원곡 제목으로 매칭했다가, 가이드 자체 id 5곡이 Supabase `slug`와 어긋나 있는 걸 발견해 가이드 id를 slug 기준으로 통일하고 slug 매칭으로 교체
  - 아이콘을 원형 배경 + 호버 확대·색상 전환이 있는 공용 버튼(`IconLinkButton`)으로 통일하고, 브라우저 기본 `title` 대신 커스텀 툴팁(호버/터치/키보드 포커스 모두 대응) 적용
  - 버그 수정: 우측 정렬된 아이콘의 중앙 정렬 툴팁이 `body`의 `overflow-hidden`에 걸려 화면 밖으로 잘리던 문제 (아이콘 오른쪽 끝 기준으로 펼치도록 변경)
  - 버그 수정: 곡 제목이 줄바꿈되는 행마다 아이콘 세로 위치가 달라지던 문제 (아이콘을 별도 테이블 셀 대신 제목과 같은 줄에 배치)
- 홈으로/뒤로가기 버튼을 공용 컴포넌트(`BackLink`/`HomeLink`)로 통합
  - 즛토피아의 URL 뎁스 기준 뒤로가기(히스토리 대신 상위 경로를 직접 계산)는 그대로 유지, 나머지는 기존처럼 `router.back()` 사용
  - 화면마다 제각각이던 스타일(필/아이콘 전용/텍스트 링크)을 즛토피아 상단 nav가 쓰던 필(pill) 디자인 하나로 통일
- 즛토피아 허브·디스코그래피·카테고리 페이지 헤더를 공용 컴포넌트(`ZutopiaSectionHeader`) 하나로 통일
  - 허브 카드에 실제 이미지를 적용, 평소엔 어둡게 눌러뒀다가 호버 시 밝아지는 효과 추가, 정사각형 비율로 변경
  - 디스코그래피 카드에 실제 곡/앨범 수, 지난 공연 카드에 타입별(콘서트/페스티벌) 개수 표시
- 버그 수정: 홈 화면 다음 공연 카드 제목·아이콘에 브레이크포인트 디버그용 글자색이 남아있던 것 제거, 공백이 포함된 유효하지 않은 Tailwind arbitrary value(`max-w-[max(30dvw, 50rem)]`) 때문에 넓은 화면에서 카드가 의도보다 훨씬 좁아져 날짜·장소가 잘려 보이던 문제 수정
