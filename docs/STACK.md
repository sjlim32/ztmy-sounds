# 기술 스택

| 영역          | 사용 기술                                                                                                                                                                                                                                                                                       |
| ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 프레임워크    | Next.js 16 (App Router, Turbopack)                                                                                                                                                                                                                                                              |
| UI            | React 19, TypeScript                                                                                                                                                                                                                                                                            |
| 패키지 매니저 | pnpm                                                                                                                                                                                                                                                                                            |
| 스타일        | Tailwind CSS v4 — 커스텀 브레이크포인트(`tablet`/`pc`/`wide`)와 색상 토큰(`ztmy-*`) 시스템                                                                                                                                                                                                      |
| 포맷터        | Prettier + `prettier-plugin-tailwindcss` (`pnpm format`)                                                                                                                                                                                                                                        |
| 콘텐츠        | MDX (`@next/mdx`) — 줄글 콘텐츠 전용                                                                                                                                                                                                                                                            |
| PWA           | `@serwist/turbopack` (오프라인 캐싱)                                                                                                                                                                                                                                                            |
| 영상 재생     | YouTube IFrame API                                                                                                                                                                                                                                                                              |
| 아이콘        | 커스텀 SVG 컴포넌트 (`src/components/icons/`) — 외부 아이콘 라이브러리 미사용                                                                                                                                                                                                                   |
| 폰트          | LINE Seed KR(로컬, `src/fonts/`)/JP(`@fontsource/line-seed-jp`, 첫 화면 뒤 동적 로드), IBM Plex Mono·RocknRoll One(Google Fonts, RocknRoll은 공연 상세만) — 851MkPOP(로컬 폰트). 로컬 폰트는 `subset-font`로 만든 서브셋을 로드(`scripts/subset-fonts.mjs`, LINE Seed KR은 기본·나머지 두 조각) |
| 데이터베이스  | Supabase (`src/lib/supabase/`) — zutopia 곡/앨범 DB. `output: "export"` 정적 빌드라 빌드 타임 전용 클라이언트만 사용                                                                                                                                                                            |
| 배포          | Cloudflare Pages (`wrangler.jsonc`, `pnpm pages:deploy`)                                                                                                                                                                                                                                        |
| 테스트        | Vitest (`pnpm test`) — 데이터 가공·계산 같은 순수 로직만(`src/**/*.test.ts`), 화면 컴포넌트 테스트 없음                                                                                                                                                                                         |
| 이미지 생성   | `html-to-image` — 참전 기록 이미지(1080×1080 PNG)를 화면 밖 DOM에서 만든다(`attendance/share/`)                                                                                                                                                                                                 |
| QR 코드       | `uqr` — 참전 기록 이미지의 QR(SVG로 직접 그림)                                                                                                                                                                                                                                                  |
